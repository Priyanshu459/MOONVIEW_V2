# Moonview Branding Assets

This directory contains the central branding assets and design tokens for the Moonview project.

## Directory Structure
- `dev/`: Contains placeholder/development branding assets (like the SVG dev mark) to be used during active development so we do not hardcode arbitrary production logos.
- Production assets will be dropped in here later.

## Usage
When changing visual elements in Moonview Web or Android, source visual inspiration and specific assets from this directory.
